PHASE 01

Schema Validation Gate

The Swarm Planner at the conference table writes a strict plan.json. If cycle loops, undefined roles, or missing criteria are detected, the plan is rejected before any desk agent is dispatched.

PHASE 02

Topological Git Worktree Chaining

Each specialist runs on an isolated Git worktree branch. Independent tasks run in parallel, while downstream tasks cleanly inherit upstream commits upon completion.

PHASE 03

Autonomous Desk Turnover

Once acceptance criteria pass, the specialist stands up, vacates the desk, commits the branch, and notifies dependent workers in the room to take their seats.

Frequently Asked Questions

Everything you need to know about Agentic Hub architecture and deployment.

How does Git worktree isolation prevent merge conflicts? +
Every specialist worker operates in a separate Git worktree directory linked to a dedicated task branch (e.g., task-1-navbar-hero). They never touch files in your active working directory. Once the worker passes all acceptance criteria, the branch is cleanly merged into the integration pipeline.
Do my repository files or code leave my computer? +
No. Agentic Hub runs 100% locally on your machine. Your local Git repository, worktree directories, and terminal commands execute on your host machine. Only LLM API calls are routed using your own configured provider keys.
How does the Swarm Planner prevent hallucinated dependencies? +
The Planner at the conference table inspects the actual codebase structure before creating plan.json. The output is validated against a strict schema that checks for cyclic graphs, invalid task IDs, and missing criteria. If validation fails, the meeting requests a revision automatically.
Can teammates on other laptops join my 3D office without installing? +
Yes! By launching with --share (or double-clicking AgenticHub-Share-Multiplayer.bat), Agentic Hub generates an instant Cloudflare Edge Tunnel link (e.g., https://xxxx.trycloudflare.com/join#ROOM-61DFE3). Teammates on any browser in the world can join your 3D office with zero installation.
